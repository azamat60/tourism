# Nomad Discovery Tours

Multilingual Kyrgyzstan travel landing page built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Run `npm run build` to export static pages into `out/`.

Languages: English, Spanish, French, Italian, German (`/ge/`), Russian, Chinese, Arabic. Update text in `lib/content.ts`. Update WhatsApp number in `components/Home.tsx`.
